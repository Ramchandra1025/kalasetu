# KalaSetu

AI-powered market intelligence and global market linkage platform for Indian artisans.

## MVP stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python + Flask
- Database/Auth/Storage: Supabase
- Authentication: Mobile OTP
- Location: Browser Geolocation API
- AI/ML/DL: Python model layer
- Research: datasets, experiments, evaluation

## Run backend
1. Open `backend/`.
2. Create/activate a virtual environment.
3. `pip install -r requirements.txt`
4. Copy `.env.example` to `.env`.
5. Add your Supabase URL and key.
6. Run `python app.py`.

API: `http://127.0.0.1:5000`
